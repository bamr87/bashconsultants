{%- comment -%} constellation.html — render any shape as an interactive cloud of light. The markup half of assets/js/constellation.js. A scene (or a timeline of scenes) is YAML under _data/constellations/.yml; this include emits it as JSON for the engine, so animations are designed as data and reviewed in a diff. Without JavaScript, or in a browser with no canvas, only the fallback you pass renders. Usage: {% include constellation.html scene="bash-mark" shape="brand/mark-shape.svg" fallback=site.logo alt="BASH Consulting logo" %} {% include constellation.html scene="terminal-demo" aspect="16 / 10" size="min(100%, 720px)" %} Parameters: scene name of a file in _data/constellations/ (required unless config is given) config a config object instead of a scene file (e.g. from page front matter) shape an include path for an inline SVG the svg source samples by default fallback image URL shown when the engine cannot run; alt is its alt text size CSS width of the stage (default clamp(220px, 55vw, 400px)) aspect CSS aspect-ratio of the stage (default 1 / 1) background "dark" (default) paints a deep-navy stage with rounded corners — additive light needs a dark ground; "none" for a host that is already dark, like the homepage hero band label aria-label for the pointer/keyboard control hint short hint text under the stage ("" hides it) particles override the pool size for this instance The accent colors default to the logo palette from `theme_color` in _config.yml (data-accents), so the brand's file of record stays the single source of truth unless a scene declares its own palette. Styles are inline on purpose: the stage is often above the fold, and a stylesheet request from inside would flash the fallback before it loaded. {%- endcomment -%} {%- assign tc = site.theme_color -%} {%- assign cfg = include.config -%} {%- if include.scene -%}{%- assign cfg = site.data.constellations[include.scene] -%}{%- endif -%} {%- assign stage_size = include.size | default: "clamp(220px, 55vw, 400px)" -%} {%- assign stage_aspect = include.aspect | default: "1 / 1" -%} {%- assign stage_label = include.label | default: cfg.label | default: "Drag or use arrow keys to rotate; click to send a wave" -%} {%- assign stage_hint = include.hint | default: cfg.hint | default: "Drag to rotate · click to ripple" -%} {%- assign stage_bg = include.background | default: "dark" -%}
