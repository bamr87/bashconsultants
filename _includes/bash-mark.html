{%- comment -%} bash-mark.html — the BASH B mark as an interactive, rotating cloud of light. A canvas rendering of the mark as a few thousand glowing particles: it turns on its own, follows a pointer drag with inertia, answers the arrow keys for keyboard users, and scatters under a hovering pointer, harder and wider the faster the pointer moves, before springing slowly back into shape. The geometry is the inline SVG include below (generated from assets/brand/favicon.svg by scripts/generate_mark_shape.py); the behavior is assets/js/bash-mark.js. Without JavaScript, or in a browser with no canvas, the static mark stays in place and nothing else renders. Usage: {% include bash-mark.html %} {% include bash-mark.html size="clamp(200px, 55vw, 360px)" particles="1800" %} Parameters (all optional): size CSS length for the square the mark occupies particles particle count at full size (scaled by area on small screens) spin idle rotation in radians per second ("0" disables it) depth slab thickness as a fraction of the mark's half-size hover "0" turns off the pointer reaction (the drag still works) The accent colors are the logo palette from `theme_color` in _config.yml, so the brand's file of record stays the single source of truth. The styles are inline on purpose: the mark sits above the fold, and a stylesheet request from inside would flash the fallback before it loaded. {%- endcomment -%} {%- assign tc = site.theme_color -%} {%- assign mark_size = include.size | default: "clamp(220px, 55vw, 400px)" -%}
